## 💡 About the Project

ExamEase is a web-based platform that simplifies online examination management.

It provides administrators with tools to create and manage examinations, while students can attempt timed assessments, submit answers, and track their results through a single platform.

## ✨ Features

### 🛡️ Admin Module
- Secure administrator login
- Create, edit and delete examinations
- Manage examination questions
- Control student examination access
- Manage student accounts
- View examination results
- Monitor student performance

### 👩‍🎓 Student Module
- Student registration and login
- Personalized dashboard
- View available examinations
- Attempt timed assessments
- Navigate between questions
- Mark questions for review
- Automatic answer saving
- View results and examination history

### 📝 Examination System
- ⏱️ Timed examinations
- 💾 Automatic answer saving
- 🔄 Question navigation
- 📌 Mark for review
- 📤 Automatic submission on timeout
- 📊 Automatic evaluation and result generation

## ⚙️ Getting Started

### Prerequisites
- Java JDK 25
- Git
- VS Code / IntelliJ IDEA / Eclipse

### 1. Clone the Repository

```bash
git clone https://github.com/ApoorvaDeshpande-10101/ExamEase.git
```

### 2. Open the Project

```bash
cd ExamEase
```

### 3. Run the Application

**Windows:**

```powershell
.\mvnw.cmd spring-boot:run
```

**macOS / Linux:**

```bash
./mvnw spring-boot:run
```

### 4. Access the Application

Open your browser:

`http://localhost:8080`
