## 💡 About the Project

**ExamEase 2.0** is a web-based examination management platform designed to simplify the process of conducting and attempting online examinations.

It provides a centralized environment where administrators can create and manage examinations, while students can participate in timed assessments, submit answers, and track their results.

Built with Java and Spring Boot, the application focuses on structured examination workflows, role-based access, and a smooth user experience.

## ⚙️ Getting Started

Want to run ExamEase locally? Follow these steps.

### Prerequisites

- Java JDK 25
- Git
- VS Code / IntelliJ IDEA / Eclipse

### 1. Clone the Repository

```bash
git clone https://github.com/ApoorvaDeshpande-10101/ExamEase.git
```

### 2. Navigate to the Project

```bash
cd ExamEase
```

### 3. Start the Application

**Windows PowerShell:**

```powershell
.\mvnw.cmd spring-boot:run
```

**macOS / Linux:**

```bash
./mvnw spring-boot:run
```

### 4. Open in Browser

```text
http://localhost:8080
```
